Projetos

Projeto 1: Sistema de Estacionamento Alugável.
Este projeto consiste em um sistema de estacionamento onde o usuário pode alugar uma vaga por um determinado período de tempo. O sistema deve permitir que o usuário faça login, reserve uma vaga, cancele a reserva e visualize o histórico de reservas.
O sistema foi desenvolvido em Python, utilizando o framework Flask para o backend e HTML/CSS para o frontend. O banco de dados utilizado foi o MySQL.

Projeto 2: Sistema de Gerenciamento de Tarefas.
Este projeto consiste em um sistema de gerenciamento de tarefas onde o usuário pode criar, editar e excluir tarefas. O sistema deve permitir que o usuário faça login, visualize suas tarefas e marque as tarefas como concluídas.
O sistema foi desenvolvido em Python, utilizando o framework Flask para o backend e HTML/CSS para o frontend. O banco de dados utilizado foi o MySQL.
